# sisuhaldussusteemid-eksam

## kood: EX-2026-NDY3

## millise CMS-i valisid ja miks
 Valisin WordPressi, minu jaoks tundus see kõige arusaadavam - Paigaldus + veebilehe ülesehitus blokkide kaupa.
 Enamus asjad saab läbi GUI ära tehtud.

 ### Tööplaan
- wordpress install
- vajalike pluginate install
- leheküljed
- theme seadistus
- sisustamine
- kujundus

### Kasutatud pluginad
- Advanced Custom Fields
- Create Block Theme
- Custom Post Type UI
- WPForms Lite

### Kokkuvõte
Uue WordPressi install sujus hästi ei olnud probleeme. 

- ddev config --project-type=wordpress
- ddev start
- ddev wp core download
- ddev wp core install


Esimese asjana alustasin wordpressis vajalike pluginate installiga.

Seejärel lehekülgede tegemisest(esieleht,uudised, kontakt).
- esileht
- uudised
- kontakt

Seejärel said tehtud lehekülje teema(theme).
- front page
- blog home
- pages
- single posts
- single-team (ACF ja CPT jaoks - saaks kuvad eraldi meeskonna liikmeid)

Kui teema põhistruktuur oli valmis, keskendusin lehtede sisustamisele ning piltide lisamisele.

Viimasena sai tehtud lehekülje kujundus, piltidel radiused, varjud jne.

Suurim probleem oli meeskonnaliikmete metaandmete (custom fields) kuvamine. Väljad said loodud, aga ei õnnestunud neid veebilehel kuvada.

Kokkuvõtvalt enda arust sain hästi hakkama. Disainile oleks võibolla rohkem rõhku pannu, väljanägemine võiks ilusam olla.
